# Katalog Skills

Snapshot: 8 September 2026. Total **437 skill unik**: **123 skill lokal/sistem** dan **314 skill plugin**.

Dokumen ini adalah inventaris dan panduan routing yang dapat dikirim ke ChatGPT. Daftar ini tidak otomatis memasang skill atau memberi akses ke tool. Agar sebuah skill dijalankan secara penuh, ChatGPT tetap memerlukan isi `SKILL.md` terkait dan tool/dependensi yang disebutkan oleh skill tersebut.

## Instruksi untuk ChatGPT

> Gunakan katalog ini untuk memilih skill yang paling relevan dengan permintaan saya. Sebutkan skill yang dipilih sebelum bekerja. Jangan mengklaim skill sudah aktif jika isi `SKILL.md` atau tool pendukungnya tidak tersedia; minta saya mengunggah isi skill yang diperlukan. Untuk nama dengan format `plugin:skill`, pertahankan namespace plugin saat merujuknya.

## Legenda scope

- `Global`: tersedia lintas project dari direktori skill pengguna.
- `Project`: tersedia khusus project Card Management.
- `Codex canonical`: terpasang pada direktori Codex utama.
- `Codex active`: tersedia pada akun/sesi Codex aktif, termasuk skill sistem.
- `… plugin`: disediakan plugin aktif; nama ditulis sebagai `plugin:skill`.
